# 오늘 뭐먹지?

월별 제철 재료로 메뉴를 고르는 식단 추천 웹사이트입니다.

## 기능

- 현재 월을 기본으로 선택하고 1~12월로 변경
- 월별 제철 재료 표시 및 재료별 레시피 필터
- 사진, 메뉴명, 요리 종류와 조리 방법 표시
- 조건에 맞는 레시피가 없을 때 안내 표시
- 같은 폴더의 menu.json을 fetch로 불러오기

## 실행 방법

파일을 내려받은 폴더에서 아래 방법 중 하나를 실행하세요.

### Node.js

```sh
node server.cjs
```

브라우저에서 http://localhost:8080 을 엽니다.

### Python

```sh
python -m http.server 8081 --bind 127.0.0.1
```

브라우저에서 http://localhost:8081 을 엽니다.

서버를 실행한 터미널을 유지하세요. Ctrl+C로 종료할 수 있습니다.
HTML 파일을 직접 더블클릭하면 브라우저의 로컬 파일 접근 제한 때문에 메뉴 데이터가 로드되지 않을 수 있습니다.

## 파일

- index.html: 화면, 스타일, 월·재료 필터 로직
- menu.json: 제철 재료와 레시피 279개
- server.cjs: 추가 패키지 없이 실행하는 로컬 Node.js 서버

메뉴 사진은 menu.json에 포함된 외부 이미지 주소에서 불러옵니다.
